# A design system is a folder of plain files in the user's repo, not a database

Each design system lives in a `design-system/` folder as versioned text: a point-of-view file, tokens (JSON), rules (Markdown, one rule per entry with its reason), components, templates, flows and a critique checklist. No database and no hosted store. The repo is the memory: diffable, reviewable in pull requests, and readable by Claude directly. This is the "encode your standards into the machine" move from the talk, in a form teams already version.
