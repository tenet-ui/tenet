# The Stripe reference system is unofficial, built from public sources, and ships no Stripe marks

The reverse-engineered Stripe system is built only from publicly observable material (the Stripe website, public talks and articles, documented colours and typography as seen in the wild). It is labelled as an unofficial reverse engineering, with attribution and a link to the sources. The package ships no Stripe logos, wordmarks or brand assets, so no output can be mistaken for Stripe's own. Anything not observable publicly is left out rather than guessed.

Stripe's Mark Usage Terms treat trade dress and design elements as marks, and no public brand guideline permits third-party reuse of its visual identity. So the pack ships no font files (Söhne is licensed separately), and its palette, type and layout are designed from observed patterns rather than copied from stripe.com. Source and confidence for every claim live in `docs/research/stripe-design-system.md`.
