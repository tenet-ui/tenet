# Launch storyboard

Six scenes that announce a product launch. Each scene has a duration, an entrance, an exit and a pacing note. The pace speeds up through the middle and the last scene holds.

1. **Hook.** Duration: 4 seconds. Entrance: title reveal. Exit: fade on `motion.depart` over `motion.duration-fast`. Pacing: slow, to set the tone. Next: scene 2.
2. **Problem.** Duration: 5 seconds. Entrance: title reveal, then one supporting line. Exit: `motion.duration-fast`. Pacing: steady. Next: scene 3.
3. **Feature one.** Duration: 4 seconds. Entrance: feature showcase. Exit: `motion.duration-fast`. Pacing: quicker. Next: scene 4.
4. **Feature two.** Duration: 3 seconds. Entrance: feature showcase. Exit: `motion.duration-fast`. Pacing: quickest; this is the middle of the film. Next: scene 5.
5. **Proof.** Duration: 5 seconds. Entrance: number counter. Exit: `motion.duration-fast`. Pacing: slows, so the figure can be read. Next: scene 6.
6. **Call to action.** Duration: 6 seconds. Entrance: title reveal. Exit: none. Pacing: holds still to the end. End scene.
